# Forever Atlas releases

Official Windows companion and WoW addon downloads for [foreveratlas.app](https://foreveratlas.app).

The service currently requires a verified, invited account. The companion installs the addon, captures its visible color strip, and publishes map state to your signed-in browser. No second-monitor software is required.

Use Preview during the invited beta. Companion and addon updates are checked automatically but installed only when you choose. Windows executables are not yet Authenticode-signed; update manifests are signed with the pinned Forever Atlas release key.

This repository distributes releases. Source is maintained separately. No imported game artwork or personal caches are included.
